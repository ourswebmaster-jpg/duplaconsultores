# Dupla Consultores

Site institucional da Dupla Consultores ([duplaconsultores.pt](https://duplaconsultores.pt)), construído em [Next.js](https://nextjs.org).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Deploy

Ligado à Vercel via integração Git — cada push para a branch principal gera um deploy automático.
